# 520 浪漫表白网页

这是一个专为520设计的浪漫表白网页，包含动态粒子爱心矩阵、水晶牌特效、手写字体动画等多种浪漫元素。

## 特点

- **极简轻奢风格**：香槟金与玫瑰粉渐变背景，搭配珍珠白文字
- **动态粒子爱心矩阵**：200+微型跳动爱心组合成巨型3D心形轮廓
- **中心悬浮水晶牌特效**：亚克力质感透明面板，边缘流光效果
- **文字动画**：手写字体逐笔出现效果
- **背景特效**：飘落玫瑰花瓣+随机出现的情话气泡
- **全响应式设计**：适配各种设备，特别是移动端
- **轻量化设计**：快速加载，流畅运行
- **丰富的交互效果**：点击爱心涟漪、嗅闻玫瑰香气彩蛋等

## 快速开始

1. 下载或克隆本项目到本地
2. 直接打开 `index.html` 文件即可在浏览器中查看效果
3. 点击右上角的设置图标，可以自定义名字、纪念日和情书内容

## 自定义指南

### 基本信息自定义

点击页面右上角的设置图标，可以自定义以下内容：

- **你的名字**：显示在标题和情书署名处
- **对方名字**：显示在标题处
- **纪念日**：用于计算相爱天数
- **情书内容**：点击中间爱心按钮显示的情书内容

所有设置会保存在浏览器的本地存储中，下次访问时自动加载。

### 高级自定义

如果你有一定的前端基础，可以通过修改源代码进行更深度的自定义：

#### 修改颜色风格

在 `css/style.css` 文件中，修改根变量可以改变整体配色：

```css
:root {
    --primary-color: #f8c9d4; /* 玫瑰粉 */
    --secondary-color: #f0d6a8; /* 香槟金 */
    --text-color: #ffffff; /* 珍珠白 */
    /* 其他颜色变量 */
}
```

#### 修改情话内容

在 `js/script.js` 文件开头，可以修改随机出现的情话内容：

```javascript
const loveQuotes = [
    "爱情是一种甜蜜的痛苦，痛并快乐着。",
    "世界上最遥远的距离不是生与死，而是我站在你面前，你却不知道我爱你。",
    // 添加或修改更多情话
];
```

#### 修改背景音乐

在 `index.html` 文件中，找到 audio 标签，修改 source 的 src 属性：

```html
<audio id="background-music" loop>
    <source src="你的音乐URL" type="audio/mpeg">
</audio>
```

## 部署指南

### 本地部署

直接将整个文件夹上传到你的网站服务器即可。

### 使用 GitHub Pages 免费部署

1. 在 GitHub 创建一个新仓库
2. 上传本项目所有文件
3. 在仓库设置中启用 GitHub Pages 功能
4. 几分钟后，你的网页就可以通过 `https://你的用户名.github.io/仓库名` 访问了

### 使用 Vercel 或 Netlify 免费部署

1. 注册 [Vercel](https://vercel.com) 或 [Netlify](https://netlify.com) 账号
2. 导入你的 GitHub 仓库
3. 自动部署完成后，你会获得一个可访问的网址
